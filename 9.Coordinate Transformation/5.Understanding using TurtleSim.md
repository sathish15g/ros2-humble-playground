# ROS 2 TurtleSim Kinematics - Detailed Explanation

This is an excellent **practical example of coordinate transformation** in ROS 2! Let me break it down comprehensively.

---

## **What This Code Does**

This code demonstrates **coordinate frame transformation** between two simulated robots (turtles) in TurtleSim. It calculates:

* **Translation vector** from turtle1 to turtle2
* **Rotation matrix** showing the angular difference between them

In essence, it answers: *"If turtle1 is at the origin, where is turtle2, and how is it rotated?"*

### **Callback Functions**

#### **Turtle1 Callback**

```python

  
def turtle1PoseCallback(self, pose):
    self.last_turtle1_pose_ = pose
```

ⓘ

* Triggered whenever turtle1's pose is published
* Simply **stores the latest pose** in memory
* No calculations (that happens in turtle2's callback)

#### **Turtle2 Callback (The Key Function)**

```python

  
def turtle2PoseCallback(self, pose):
    self.last_turtle2_pose_ = pose
```

ⓘ

Stores turtle2's latest pose.

```python

  
Tx = self.last_turtle2_pose_.x - self.last_turtle1_pose_.x
    Ty = self.last_turtle2_pose_.y - self.last_turtle1_pose_.y
```

ⓘ

**Translation Vector Calculation:**

This computes how far turtle2 is from turtle1 in the  **global reference frame** .

T**x****=**x**2−**x**1 ****T**y****=**y**2****−**y**1******Example:**

* If turtle1 is at (1, 2) and turtle2 is at (4, 6):
* **T**x=**4**−**1**=**3** (3 units to the right)
* **T**y=**6**−**2**=**4** (4 units up)

```python

  
theta_rad = self.last_turtle2_pose_.theta - self.last_turtle1_pose_.theta
    theta_deg = 180 * theta_rad / 3.14
```

ⓘ

**Rotation Angle Calculation:**

θ**r**a**d****=**θ**2−**θ**1**Converts radians to degrees for readability:

θ**d**e**g****=**π**180**×**θ**r**a**d> **Note:** The code uses 3.14 instead of `math.pi` (less precise, but close enough)

---

### **Rotation Matrix Construction**

```python

  
math.cos(theta_rad), -math.sin(theta_rad),
    math.sin(theta_rad), math.cos(theta_rad)
```

ⓘ

Builds the  **2D rotation matrix** :

R**=**(**cos**(**θ**)**sin**(**θ**)−**sin**(**θ**)**cos**(**θ**))

 This matrix rotates any point by angle **θ** counterclockwise.

## **Potential Improvements**

```python

# Add inverse transformation
def transform_point(self, point, Tx, Ty, theta):
    """Transform a point from turtle1 frame to turtle2 frame"""
    # Translate
    x_trans = point[0] - Tx
    y_trans = point[1] - Ty
  
    # Rotate
    x_rot = x_trans * math.cos(theta) + y_trans * math.sin(theta)
    y_rot = -x_trans * math.sin(theta) + y_trans * math.cos(theta)
  
    return (x_rot, y_rot)
```
