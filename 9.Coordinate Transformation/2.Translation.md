# Translation in Coordinate Transformation - Simple Example 🤖

Let's understand translation with a simple scenario you can visualize.

---

## **Scenario: Two Robots in a Warehouse**

Imagine you have:

* **Robot A:** Your reference point (origin of the coordinate frame), standing still.
* **Robot B:** A delivery robot you want to track.

Both robots are moving in a warehouse. We'll see how the translation vector changes.

---

## **Initial Setup (Time: t = 0 seconds)**

```
Warehouse Layout (Bird's Eye View):

        Y-axis (North)
          ↑
          |
    ┌─────┼─────┐
    |     |     |
    |  A  |     |     X-axis (East)
    |  ●  |     | ─────→
    |     |     |
    |     |  B  |
    |     |  ●  |
    └─────┼─────┘
```

**Positions:**

* Robot A: (x₁ = 0, y₁ = 0) - Origin, standing still
* Robot B: (x₂ = 3, y₂ = 2) - 3 meters east, 2 meters north

**Translation Vector Calculation:**

Tx = x₂ - x₁ = 3 - 0 = 3 meters  
Ty = y₂ - y₁ = 2 - 0 = 2 meters

**Output:**

```
Translation Vector from Robot A to Robot B
Tx: 3.000000
Ty: 2.000000

Distance: 3.606 meters
Direction: Northeast (33.7° from East)
```

---

## **After Movement (Time: t = 5 seconds)**

Robot B moves 2 meters east.

```
Y-axis (North)
          ↑
          |
    ┌─────┼─────┐
    |     |     |
    |  A  |     |     X-axis (East)
    |  ●  |     | ─────→
    |     |     |
    |     |     |  B
    |     |     |  ●
    └─────┼─────┘
```

**New Positions:**

* Robot A: (x₁ = 0, y₁ = 0) - Still at origin
* Robot B: (x₂ = 5, y₂ = 2) - Moved east

**Updated Translation Vector:**

Tx = 5 - 0 = 5 meters (increased)  
Ty = 2 - 0 = 2 meters (same)

**Output:**

```
Translation Vector from Robot A to Robot B
Tx: 5.000000  (changed)
Ty: 2.000000  (unchanged)

Distance: 5.385 meters
Direction: Northeast (21.8° from East)
```

**What Changed?**

- Robot B moved east, so Tx increased.
- Ty stayed the same (no north-south movement).

---

## **Key Points**

- Translation tells you how to move from one point to another.
- It's always: Target position minus Reference position.
- Tx is the east-west difference, Ty is north-south.
- The vector changes as positions change.

This is the basics of translation in coordinate transformations!
