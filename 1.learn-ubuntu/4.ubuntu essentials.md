2. Working with Package Managers

---

### 📌 Short & Crisp Info

Package managers install, update, and remove software automatically with dependency handling.

### 🔹 Common Package Managers

| Distro        | Package Manager | Example Command          |
| ------------- | --------------- | ------------------------ |
| Ubuntu/Debian | APT             | `sudo apt install git` |
| Fedora/RedHat | DNF             | `sudo dnf install git` |
| Arch Linux    | Pacman          | `sudo pacman -S git`   |

### 🧪 Lab (Ubuntu)

```bash
sudo apt update
sudo apt install tree -y
tree
```

✅ You installed and tested a package.

3. Version Control with Git in Linux

---

### 📌 Short & Crisp Info

Git tracks code changes and enables team collaboration. Linux terminals are optimized for Git workflows.

### 🔹 Basic Git Commands

```bash
git init
git add .
git commit -m "first commit"
git push
```

### 🧪 Lab

```bash
git init
echo "Linux Git Lab" > README.md
git add .
git commit -m "Initial commit"
```

✅ You created your first Git commit.

4. Network Configuration & Diagnostics

---

### 📌 Short & Crisp Info

Linux provides powerful tools to inspect and debug networks.

### 🔹 Important Commands

| Command      | Purpose            |
| ------------ | ------------------ |
| `ip a`     | Show IP addresses  |
| `ping`     | Check connectivity |
| `ss -tuln` | Show open ports    |
| `scp`      | Secure file copy   |
| `rsync`    | Fast backups/sync  |

### 🧪 Lab

```bash
ip a
ping -c 3 google.com
ss -tuln
```

✅ You verified IP, internet, and running services.

5. Customization: Make Linux Yours

---

### 📌 Short & Crisp Info

Linux allows full control over UI, startup apps, themes, and terminal behavior.

### 🔹 Customization Options

- Desktop Environments: GNOME, KDE, XFCE
- Bash aliases
- Startup apps
- Themes & window managers

### 🧪 Lab: Create a Bash Alias

```bash
echo "alias ll='ls -lh'" >> ~/.bashrc
source ~/.bashrc
ll
```

✅ You customized your terminal.
